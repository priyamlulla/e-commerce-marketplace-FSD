# ShopSphere — E-Commerce Marketplace

A full-stack e-commerce marketplace built using React, Tailwind CSS, Node.js, Express.js, and MongoDB.

## 🚀 Live Demo

**Live Website:** https://e-commerce-marketplace-fsd.vercel.app/

**Backend API:** https://shopsphere-backend-api-cr6p.onrender.com/

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- GitHub Actions

## ✨ Key Features

- Responsive user interface
- Product catalog
- Shopping cart
- REST API with CRUD operations
- Authentication functionality
- MongoDB database integration
- Automated testing and deployment workflows
